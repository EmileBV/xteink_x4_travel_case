# xteink x4 travel case

Dual purpose case for the xteink x4 that covers the screen and buttons for travel in one position and serves as a regular case in the other position.

> [!Note]
> The `x4_travel_case.mf3` file is setup for Bambu Studio. It has the same `.stl` twice. One is setup with a modifier that allows to have inner infil as the back of the case. This works well to give the case a unique look. However, low infill percentages will result in an overly flexible case that may not be as secure.
